แปลง JSON ↔ Excel

JSON → Excel

ลากไฟล์ .json มาวาง หรือคลิกเพื่อเลือกไฟล์

Excel → JSON

สร้างโค้ด Bookmarklet (เช็คอินจากมือถือด้วยการกดครั้งเดียว)

      

        
โค้ดนี้คำนวณวันที่/WFH-WFO จากวันที่กดจริงเสมอ (ไม่ใช่ค่าตายตัว) โดยใช้โครงการที่เลือกไว้ด้านบน กดปุ่มเพื่อสร้าง แล้วนำไปตั้งเป็น Bookmark ตามขั้นตอนด้านล่าง

        
        
        

          
        

        

        

          วิธีติดตั้งบนมือถือ
          
iPhone (Safari): เปิดเว็บอะไรก็ได้ → แตะไอคอนแชร์ → "Add Bookmark" → บันทึก → ไปที่ Bookmarks → แก้ไข bookmark ที่สร้างไว้ → เปลี่ยนชื่อเป็น "AMO เช็คอิน" → ลบ URL เดิมออกแล้ววางโค้ดด้านบนแทน → บันทึก

          
Android (Chrome): เมนู ⋮ → Bookmarks → Add bookmark → ตั้งชื่อ "AMO เช็คอิน" → ลบ URL เดิมแล้ววางโค้ดด้านบนแทน → Save
